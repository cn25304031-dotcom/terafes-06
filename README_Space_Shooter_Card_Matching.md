# Space Shooter × Card Matching

宇宙をテーマにした **Space Shooter** と **Card Matching** を組み合わせたミニゲームのUIスケッチです。  
添付されたモックアップを参考に、タイトル画面、モード選択、ゲームプレイ、成功、ゲームオーバー、クリア結果までの画面構成を整理しています。

> **注意:** 本プロジェクトは最終製品ではなく、ゲームUI・画面遷移・デザイン方向性を確認するための **ラフスケッチ / プロトタイプ** です。

---

## 主な機能

- **タイトル画面** — Space Shooter × Card Matching のゲームタイトル
- **モード選択** — Space Shooter / Card Matching を選択
- **Space Shooter** — 宇宙船を操作して敵を倒し、スコアを獲得
- **Card Matching** — カードをめくって同じ絵柄のペアを探す
- **ペア成功演出** — ペアを見つけたときの簡単なエフェクト
- **ゲームオーバー** — スコア、時間、手数を表示
- **クリア結果** — クリア時のスコア、時間、手数を表示
- **リプレイ** — ゲームをもう一度プレイ
- **タイトルへ戻る** — タイトル画面へ戻る

| 画面 | 内容 |
|------|------|
