# 01_要件定義・画面仕様書

## 1. システム概要
本システムは、イベント（TERA FES 2026）向けに制作されたWebベースのレトロ・フューチャー風アーケードゲームプラットフォームである。
プレイヤーはタイトル画面からゲームを選択し、ブラウザ上で動作するシューティングゲームや神経衰弱ゲームをプレイすることができる。

---

## 2. 機能要件 (Requirements)

### 2.1 全体・共通機能
1. **多言語対応 (i18n)**
   - 日本語 (JA) をはじめとする複数言語の切替表示に対応する。
   - 言語切替メニューから動的にラベルテキストが切り替わる。
   - ミャンマー語表示時はフォント設定および行間・文字間隔が最適化される。

2. **テーマ切替機能**
   - ダークモード (Dark - デフォルト) とライトモード (Light) のテーマ変更が可能。
   - 選択されたテーマに応じて背景グラデーション、グリッド、ガラスエフェクト、テキスト色などが切り替わる。

3. **サウンド・BGM制御**
   - BGM/効果音のON/OFF切り替え用ボタンを提供する。
   - ユーザー操作前のブラウザにおける音声自動再生制限に対応し、初回タップ・操作時にサウンドコンテキストを有効化するプロンプト/ヒントを表示する。

4. **アトラクトモード (放置演出)**
   - スタートボタンを押さずに一定時間放置した場合、ボタンの拡大・脈動アニメーション（ジャンプ・ショックウェーブ効果）でプレイヤーの視線を引く。

5. **アニメーションバックグラウンド**
   - Canvasを使用した動的な星空エフェクト (`#stars`)、グリッドドリフト、メッシュシフト、ビーム、フィルムグレインエフェクトによる奥行きのある宇宙背景を描画。

### 2.2 画面遷移・フロー制御
- **タイトル画面 (`#screen-title`)** $\rightarrow$ **モード選択画面 (`#screen-mode`)**
- **モード選択画面** $\rightarrow$ **各ゲームモーダル/フレーム (`#game-frame`)**
- **遊び方モーダル (`#howto`)** の表示・非表示。
- **12秒ストーリーイントロ (`#intro`)** の再生とスキップ機能。

### 2.3 収録ゲームコンテンツ
1. **Space Shooter (スペースシューティング)**
   - 自機（ロケット）を操作し、弾を射撃して敵機・ボスを撃破する2Dシューティング。
   - ステージ選択、スコア/ハイスコア保存（`localStorage`）、HP/シールド、ボスのHPゲージ管理、効果音合成（Web Audio API）を搭載。
2. **Card Matching (神経衰弱)**
   - カードを2枚めくってペアを合わせるメモリーゲーム。
   - 手数・時間計測機能を備える。

## 3. 画面仕様書 (Screen Specifications)

### 3.1 画面一覧
| 画面ID | 画面名称 | 概要 |
|---|---|---|
| SCR-01 | タイトル画面 | イベント名、メインタイトル、ゲームスタートボタン、遊び方ボタンを表示 |
| SCR-02 | モード選択画面 | 収録ゲーム（Space Shooter / Card Matching）のカード一覧選択 |
| SCR-03 | 遊び方モーダル | 各ゲームの簡易ルール説明をダイアログ表示 |
| SCR-04 | 12秒ストーリーイントロ | ゲーム開始前の演出アニメーション (シーン1〜3) |
| SCR-05 | ゲーム実行フレーム | iframeによる個別ゲーム画面の埋め込み表示 |

---

### 3.2 各画面詳細仕様

#### 3.2.1 SCR-01: タイトル画面 (`#screen-title`)
- **構成要素**:
  - **ヘッダー**:
    - イベントラベル (`TERA FES 2026`)
    - パルスビーコン表示
    - 右上固定コントロール (`.corner`): 言語切替ボタン、テーマ切替トグル、音量ON/OFFボタン
  - **メインヒーロー**:
    - タイトルテキスト: `Space Shooter × Card Matching`
    - ホバー時に文字単位でネオンカラーに発光・浮遊するインタラクティブ文字演出。
  - **アクションエリア**:
    - `PRESS START / ゲームスタート` ボタン (`#btn-start`): ネオンバタつきアニメーション＋ソナーリングエフェクト。押下時にモード選択画面へ遷移。
    - `? 遊び方` ボタン (`#btn-howto`): 押下時に遊び方モーダルを開く。

#### 3.2.2 SCR-02: モード選択画面 (`#screen-mode`)
- **構成要素**:
  - **ヘッダー**: 戻る操作用レイアウト、中央ラベル。
  - **タイトルエリア**: 「ゲームを選んでください / 遊びたいゲームをタップ」
  - **ゲームリスト (`.game-list`)**:
    - 各ゲームカード (`.game`):
      - アイコン (SVG + アニメーション)
      - タグ (`01 SHOOTER`, `02 MEMORY`)
      - タイトル・説明文
      - 矢印ボタン (`.go`)
    - カードホバー時にマウス位置に応じたグラデーションハイライト追従機能。
  - **フッター**: `戻る` ボタン (`#btn-back`): 押下時にタイトル画面に戻る。

#### 3.2.3 SCR-03: 遊び方モーダル (`#howto`)
- **構成要素**:
  - ボトムシート形式のダイアログ（モバイル最適化）。
  - **コンテンツ**:
    - Space Shooter のルール: ロケットを動かして弾を撃ち敵を倒す。シールド0で終了。
    - Card Matching のルール: 2枚めくりペアを探す。手数と時間の最小化を目指す。
  - **アクション**: `閉じる` ボタン (`#btn-close`)。

#### 3.2.4 SCR-04: 12秒ストーリーイントロ (`#intro`)
- **構成要素**:
  - 全画面 Canvas アニメーション。
  - **シーン1 (`.sc1`)**: スーツ装着演出 (`SUIT SYNC` ゲージ上昇)
  - **シーン2 (`.sc2`)**: 機体チェック演出 (`ENGINE`, `WEAPONS`, `SHIELD` の `OK` 表示)
  - **シーン3 (`.sc3`)**: 出撃・敵遭遇演出 (`BATTLE START`)
  - **コントロール**:
    - 進捗バー (`.prog`)
    - `SKIP` ボタン (`#skip`): イントロを中断して即座にゲーム画面へ遷移。

#### 3.2.5 SCR-05: ゲーム実行フレーム (`#game-frame`)
- **構成要素**:
  - 全画面 `iframe` (`#gf`) によるゲームコンテンツの独立実行。
  - **左上固定コントロール**:
    - `戻る` ボタン (`#game-exit`): 押下時にゲームを終了しモード選択画面へ復帰。

## 4. 非機能要件・デザイン仕様
1. **レスポンシブデザイン**
   - モバイル端末（画面幅 440px 以下想定）からPCディスプレイまで対応。
   - `svh` (Small Viewport Height) および Safe Area (`env(safe-area-inset-*)`) を考慮したレイアウト設定。
2. **デザインシステム・カラーパレット**
   - `--bg`: `#07080d` (Dark) / `#eef2fb` (Light)
   - `--cyan`: `#5fd4ff` (メインアクセント)
   - `--violet`: `#b99cff` (サブアクセント)
   - `--line`: `rgba(255, 255, 255, 0.09)`
   - フォントファミリ: `Sora`, `Inter`, `Noto Sans JP`, `Noto Sans Myanmar`
3. **アクセシビリティ・UI配慮**
   - フォーカスリング仕様 (`:focus-visible` 時のアウトライン).
   - ARIA属性 (`aria-expanded`, `aria-hidden`, `aria-live`, `aria-modal`) の付与によるスクリーンリーダー・状態管理対応。
